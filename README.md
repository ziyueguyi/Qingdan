# 清单（Qingdan）· Windows / Android 本地优先任务清单

一个**本地优先**的桌面任务清单：不登录完全可用；登录 Gitee 后把数据同步进**你自己的私有仓库**。
数据默认保存在设备本地。源码版本 **0.3.0**；已发布的软件包以 Releases 页面为准。

交付形态是 **Windows 桌面 exe**（onedir）：程序内部起一个只听 `127.0.0.1` 的本地服务，
在**原生窗口**里用系统 Edge WebView2 渲染界面——没有地址栏、没有标签页、**不是网站**。
用浏览器打开只是开发期调试方式。另附 `QingdanCLI.exe` 命令行入口，与桌面版共用同一套功能注册表。

Android 版为可独立离线使用的 **arm64 APK**，本地 SQLite 和业务代码与桌面版共用，
通过 Android Keystore 保护凭据。使用 Android 17 QPR2（API 37.2）SDK 构建，最低支持 Android 7.0（API 24）。

- 设计文档：[`docs/清单exe-开发文档.md`](docs/清单exe-开发文档.md)
- 验收记录：[`docs/2026-11-11-功能完善与验收.md`](docs/2026-11-11-功能完善与验收.md)、[`docs/0.2.1-设置布局验收.md`](docs/0.2.1-设置布局验收.md)

## 1. 功能总览

- **视图**：今天 / 近一周 / 收集箱（全部任务）/ 已完成 / 垃圾桶；列表 / 看板 / 日历三布局；
  按日期 / 优先级 / 标签分组，多种排序与反序；自定义过滤器。
- **任务**：标题、备注、到期（日期或日期时间、全天）、优先级 P1–P4、颜色、标签、归属清单、
  子任务、重复规则、提醒；完成 / 重开 / 跳过这次 / 贪睡 / 删除（墓碑）/ 恢复；撤销上一步。
- **添加两条路**：工具栏「＋ 新任务」弹窗（标题 / 日期+全天 / 等级 / 标签 / 清单 / 周期），
  或主区输入行自然语言速记（`明天下午3点 交材料 #重要 !P1`，回车即存，输入时下方回显识别结果）。
  普通新任务默认**明天此刻**；日历点日期共用同一弹窗、只替换日期。
- **周期任务**：单次 / 全天 / 每天 / 每周 / 每月 / 每年 / 自定义规则（独立小弹窗：间隔、星期、
  结束日期或次数；高级 RRULE）。完成自动顺延到下一次，提醒跟着平移。
- **右键菜单**：完成/重开、日期快设（今天/明天/清除/排期）、优先级、跳过这次、贪睡、创建副本、
  移动到清单、编辑、删除；垃圾桶内为恢复。主题化、边缘避让、键盘导航、动作后自动关闭。
- **清单 / 标签 / 过滤器管理**：侧栏新建、改名（行尾 ⋯）、删除；任务可移动到任意清单或收集箱；
  任务里填的标签自动进侧栏。三类目录**固定五行视口、按五条分页、预取相邻页**，滚动条隐藏；新增和编辑可选择图标，默认样式保留。见 [0.2.2 验收记录](docs/0.2.2-左侧菜单验收.md)。
- **倒数日**：生日 / 纪念日 / 截止日这类"只数日子"的条目，还剩 / 已过 N 天，支持每年重复与提前提醒。
- **提醒**：系统通知（托盘气泡→对话框降级）、钉钉机器人、邮箱 SMTP；三级开关、免打扰时段、
  每日摘要、同分钟合并发送、贪睡；设置页可看告警日志。
- **同步**：Gitee 私有仓、三方合并、冲突逐字段裁决、墓碑传播、钟差保护、凭据 DPAPI 加密。
  支持设置间隔分钟，或每天多个时间点，自动拉取和推送全部类型的增量数据。
- **数据**：每日自动备份 + 手动快照、恢复（重启生效）、CSV / JSON / Markdown 导出、JSON 导入。
- **界面**：亮 / 暗主题、6 套强调色、3 档字号、中 / 英双语（运行时切换，用户数据永不翻译）、
  左右面板可折叠（带过渡动画，尊重系统"减少动画"）、状态栏图标化计数。
- **集成**：全部功能经 HTTP / CLI / Python 三种入口可达；远程 API 默认关闭、按需开启并带 Bearer 鉴权。

## 2. 快速开始

**EXE / APK 下载页面**：[进入 Releases 下载页面](https://github.com/ziyueguyi/Qingdan/releases)

打开最新版本，展开 **Assets**，选择名称含 `windows-x64` 的 ZIP 下载。`Source code` 是源码，不是可运行软件。
解压后保留完整的 `Qingdan` 文件夹，双击其中的 `Qingdan.exe`；命令行入口为同目录的 `QingdanCLI.exe`。
这里提供的是下载页面入口，不是某个版本文件的直接下载链接。

Android 手机选择名称含 `android-arm64` 的 APK，允许当前下载应用安装后打开。
新版使用同一份固定签名，后续 APK 可覆盖升级；卸载会清除应用本地数据，请先同步或导出。
只有 Windows、Android 构建和运行检查均通过的版本才会自动发布，构建进度可在仓库 **Actions** 查看。

**用发行包**：双击解压后 `Qingdan` 文件夹内的 `Qingdan.exe`。
命令行用同目录 `QingdanCLI.exe`。两个程序及其依赖文件放在同一目录；旧版程序与数据保留在原处，
可用 `Qingdan.exe app <原数据目录>` 指定已有数据。

**从源码跑**（Python 3.14）：

```powershell
cd qingdan
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -e .[dev]
.venv\Scripts\python.exe -m qingdan app            # 原生窗口
.venv\Scripts\python.exe -m qingdan serve <dir>    # 只起本地服务（开发/调试）
```

> 默认 PyPI 直连经常超时，清华源是必需的，不是可选项。

**构建与验收**：

```powershell
.venv\Scripts\pyinstaller.exe --noconfirm packaging\qingdan.spec
.venv\Scripts\python.exe scripts\check_size.py <产物目录>     # 体积门禁 42MB，写 SIZE 留档
.venv\Scripts\python.exe scripts\verify_release.py <产物目录> # 冻结包端到端验收
.venv\Scripts\python.exe -m pytest -q                        # 全量回归测试
```

**SmartScreen**：未签名 exe 首次运行会被拦——「更多信息」→「仍要运行」，只拦一次。
杀软若拦自启注册表项，把整个产物目录加信任区。彻底消警告需代码签名证书（OV 约 ¥1500/年，未做）。
不要用 onefile 版：每次启动解包到临时目录，杀软最敏感，托盘常驻程序被拦一次就收不到提醒了。

## 3. 界面与日常操作

- **添加**：见 §1。弹窗里日期右侧是周期选择框；选「规则」打开独立小弹窗（间隔 / 星期 / 结束条件 /
  高级 RRULE），取消不会丢主表单草稿。
- **编辑 / 排期**：点任务行打开详情面板；行尾 📅 或右键「排期…」打开同一弹窗。
  详情面板折叠时，弹窗与右键菜单是唯一的排期入口。
- **日历**：周一对齐；上 / 下月与返回本月；点日期新建任务；重复任务的未来次数画成虚线框
  （展开预览，不是新任务，点开仍是同一条）。
- **折叠**：侧栏与详情面板都可收起（侧栏 226 → 77 → 56px 三档，折叠态为图标列、悬停出名字）；
  详情收起后右缘留竖排还原按钮；状态跨会话保留（设备本地偏好，不进同步）。
- **状态栏**：任务 / 逾期 / 今天 / 今日完成 / 待推送 图标化计数；右端圆点表示登录态
  （绿=已登录同步可用，灰=离线仅本机）；窗口收窄时只留图标与数字。
  数据目录位置不在状态栏显示，见 设置 → 数据。
- **撤销**：写操作后可撤销上一步（撤销是"用前像再写一个新版本"，不是回滚历史）。
- **搜索**：顶部搜索框跨任务 / 清单 / 标签；中文子串匹配（LIKE，实测两字词可命中）。

## 4. 清单、标签与过滤器

- 侧栏「清单」区：新建、行尾 ⋯ 改名 / 删除；任务弹窗与右键菜单里选择归属清单或移回收集箱；
  清单选择支持分页搜索。删除清单时其下任务转收集箱（不丢任务）。
- 标签：显式创建的与任务里填写的合并显示；改名 / 删除会同步更新任务引用。
- 过滤器：保存一组条件（逾期 / 优先级 / 标签 / 时间窗等），侧栏一点即筛。
- 目录分页：SQL 每次取五条、固定五行视口、预取下一页、只缓存相邻页——大目录不卡界面。

## 5. 重复任务（周期 / 定时）

- **必须设到期日才会循环**；只选周期没排日期，完成时不会生成下一次，界面会写明原因。
- **完成 = 这一次做完，任务继续**：到期日推到下一次、状态回待办，不堆进「已完成」；
  做过多少次在详情「完成记录」里看（**只留本机，不进同步**）。
- **跳过这次**：不算完成，直接推到下一次（记 skipped）。
- **提醒平移**：提前量不变（20:00 到期 19:30 提醒 → 明天仍 19:30）；贪睡只属于那一次，推进后失效。
- **月末不漂**：1/31 的每月任务在 2 月落 28/29；要"每月最后一天"用 `BYMONTHDAY=-1`；
  写死 `BYMONTHDAY=31` 则在没有 31 号的月份跳过（RFC 5545 语义）。
- **结束条件**：`COUNT` / `UNTIL` 用尽时最后一次正常收尾为已完成，并说明系列已结束。
- 规则子集：`FREQ=DAILY|WEEKLY|MONTHLY|YEARLY` + `INTERVAL` + `BYDAY`(周) + `BYMONTHDAY`(月/年)
  + `UNTIL` + `COUNT`。自写解析器（`core/rrule.py`），不引 dateutil；不支持的键写入时就拒绝。
- 锚点纪律：显式改到期日 / 改规则时重新下锚；自动推进不动锚（否则 COUNT 永远数不到头）。

## 6. 倒数日

工具栏「＋ 倒数日」：标题 + 目标日期，显示还剩 / 已过 N 天，支持每年重复（生日 / 纪念日）、
提前 N 天提醒、颜色。它和任务的区别：任务要勾完成，倒数日只数日子。参与同步。

## 7. 提醒与告警

- 三级开关：总开关（顶栏铃铛 / 提醒页顶部）→ 渠道开关 → 单条任务的提醒时间。铃铛状态重启保留。
- **只在程序活着时触发**：关窗口只是隐藏到托盘；退出用托盘菜单。打包版可设开机自启（开发环境不注册）。
- 系统通知默认走**托盘气泡**（未打包应用的 toast 会被 Windows 静默丢弃），托盘不可用退回到必定可见的对话框。
- 钉钉限流 20 条/分钟：同分钟到期合并成一条 + 令牌桶；业务错误藏在 HTTP 200 的响应体里
  （如 `310000` 关键词不命中），渠道测试会原话显示，不伪装成网络错误。
- 免打扰时段、每日摘要（固定时间一条汇总）、临时静音 30 分钟。
- 关机期间攒下的过期提醒启动时标"已跳过"，不补发轰炸。
- 排障三处：托盘图标在不在、设置 → 提醒 → 渠道测试 / **告警日志**、应用目录 `crash.log`。

## 8. 同步（Gitee 私有仓）

入口：设置 → 同步。令牌需 `projects` 权限；首次同步自动建仓且**强制私有**。

登录并选择远端仓库后，在「定时增量同步」启用计划：可按间隔分钟，或每天填写多个 `HH:mm` 时间。
页面显示下次执行、上次成功和错误状态；计划只保存在当前设备。桌面版需要程序运行（可留在托盘）。
Android 后台由 WorkManager 调度，间隔最低 15 分钟；省电、休眠和断网可能延迟执行，恢复后继续同步。
它使用与手动同步相同的增量、冲突和墓碑流程，不会每次全量覆盖远端。

- 同步对象：任务 / 清单 / 分组 / 小节 / 标签 / 过滤器 / 倒数日 / 备注，一条一个 JSON 文件。
- **删除是墓碑**（`deleted: true` 的新版本），不是文件消失——另一台机器才能分清"别人删了"和"我本来没有"。
- **保险丝**：仓库文件不见但无墓碑时，不删本地数据，报警告保留本地（防网页手删带走清单）。
- **新机首同步只拉不推**，不生成任何删除。
- **冲突你来裁决**：设置 → 同步「⚠ N 项冲突待裁决」，逐字段列「本机 / 另一台 / 原来」，
  单边改的已预选、双边改的必须看一眼；保留本机 / 采用另一台 / 保存合并（可逐字段选边或改写）。
  落败那份裁决前一直可取回，不静默消失。
- **钟差保护**：版本用混合逻辑时钟 `(毫秒, 序号, 设备号)`，毫秒经 Gitee 响应头校准；
  偏差超 5 分钟只拉不推并红字说明，校时后下一轮自动补推。
- **不参与同步**（设备本地）：提醒配置与密钥、主题语言、视图与侧栏偏好、折叠状态、静音、完成记录。
- **凭据安全**：令牌 / webhook / SMTP 授权码以 DPAPI 密文存 `db.sqlite` 的 `secret` 表，
  绑定当前 Windows 用户；接口只回掩码。每轮同步收尾会抹掉工作副本里所有带凭据的 URL
  （`.git/config`、reflog、`FETCH_HEAD`、数据库覆盖项）。
  **老数据目录可能仍有残留**，搬文件夹前自查：

  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts\check_token.ps1
  ```

  有残留逐行报 HIT、干净报 CLEAN（双向验证过，假阴性的自查比没有更危险）。
  命中就把 URL 的凭据段去掉，并**去 Gitee 撤销该令牌重发**——明文在磁盘待过就当泄露处理。

## 9. 数据目录与迁移

**程序产生的一切都在应用所在目录**（打包版=exe 同级，源码版=`qingdan\`）：

| 位置 | 是什么 |
|---|---|
| `<应用目录>\data\db.sqlite` | 全部数据（WAL；别单独复制它做备份，见 §10） |
| `<应用目录>\data\backups\` | 每日快照，滚动 14 份 |
| `<应用目录>\data\exports\` | 导出文件 |
| `<应用目录>\data\repo\` | 同步用本地 git 工作副本 |
| `<应用目录>\data\http.json` | 本地服务端口与一次性令牌（诊断用） |
| `<应用目录>\crash.log` | 启动崩溃现场（windowed 无控制台） |

自定义位置优先级：启动参数 `app <dir>` > 环境变量 `QINGDAN_DATA_DIR` > 应用目录 `data_dir.txt`
（相对路径按应用目录解析）。装进只读位置（Program Files）会退到用户目录并在界面说明原因。
设置 → 数据 显示当前读的是哪儿、为什么。

**旧位置迁移**（早先版本写在 `%LOCALAPPDATA%\qingdan`）：检测到旧库而新位置没有时继续读旧库
（不会让你以为清单被清空）。搬迁：

```powershell
# 先退出程序（托盘 → 退出）
.venv\Scripts\python.exe scripts\migrate_data.py           # 预演
.venv\Scripts\python.exe scripts\migrate_data.py --apply   # 复制 + 校验行数与 integrity
```

脚本**不删源数据**，校验对不上就拒绝收尾；确认新位置没问题后再自行把旧目录放回收站。

## 10. 备份、恢复、导入、导出

- 每日首启自动快照；设置 → 数据 → 立即备份另存带时分秒的快照，同日多份互不覆盖。
- **恢复需要重启**：运行中进程握着连接，热换文件是未定义行为；程序只记"待恢复"标记，
  下次启动建连接前替换，并先留 `-pre-restore` 快照可退回。恢复前校验备份完整性与结构，
  损坏备份不会被当作"最新有效备份"。
- **恢复不回滚远端**：备份带着上次同步基线，恢复后照常三方合并——备份之后被别的设备删掉的项
  会再被删一次（正确行为，否则已删项复活）。想让它回来要在另一台也回滚或重建。
- 导出：CSV（UTF-8 BOM，Excel 不乱码）/ JSON / Markdown；**表头语言跟界面语言走**，内容不变。
- 导入：设置 → 数据 → 导入，选本程序导出的 JSON；幂等合并——只写入比本地更新的版本，
  重复导入 applied=0，更旧版本跳过；回执显示 写入 / 跳过 / 无效 条数。

## 11. API 与 CLI

- 所有业务功能共用 `@feature` 注册表（启动时从注册表读取实际入口），同时派生 Python API、HTTP 路由、
  CLI 子命令；契约测试保证注册表与路由 1:1 且每个都能经 HTTP 调通。
- `QingdanCLI.exe`：标准子命令 + `call <功能名> --参数 值`；中文 JSON 输出、标准退出码；
  列表类分页响应 `total / items / limit / offset / has_more / next_offset`（默认 5 条、单页上限 100）。
- **运行中安全**：桌面版已运行时 CLI 走它的本机 HTTP 服务，不另开数据库、不提前执行待恢复操作；
  未运行时 CLI 持同一把单实例锁。写入超时不自动重试。
- **远程 API 默认关闭**。Windows 设置 → API 页分为「远程服务 / Token 管理 / 创建 Token / 调用日志」。
  可选 HTTP（不需要证书）、HTTPS（自动自签名或导入 PEM），或 HTTP / HTTPS 双端口同时运行。
  HTTP 传输未加密；HTTPS 自动证书需要调用端信任该证书。无论协议如何，远程调用都需要 Bearer Token。
  每个 Token 独立设置读/新增/修改/删除/执行权限、接口白名单、期限、QPS、累计调用上限及备注；
  表格显示调用次数、创建与最近使用时间、状态，可编辑授权或撤销。Token 原文仅创建时展示一次。
  凭据管理始终只限本机。详见 [`docs/API-CLI-访问控制方案.md`](docs/API-CLI-访问控制方案.md)。
- **CLI 单独一页且仅本机使用**，不开放远程 CLI。Android 不启动桌面 API / CLI 服务。
- 输入保护：非法 JSON / 错误类型 / 未知任务字段返回 422 校验错误，不执行写操作；
  跨站写入与异常来源被拒绝。

```powershell
QingdanCLI.exe --data-dir D:\your-data task create --title "每周复盘" --due-at "2026-11-13T09:00:00" --repeat weekly
QingdanCLI.exe --data-dir D:\your-data task update --item-id TASK_ID --changes "{\"title\":\"新标题\",\"tags\":[\"工作\"]}"
QingdanCLI.exe --data-dir D:\your-data group list --limit 5 --offset 0
```

## 12. 自启、托盘、单实例

- 开机自启：设置 → 数据 → 开关（写注册表 Run 项）；开发环境不注册，界面说明原因。
- 托盘常驻：关窗口=隐藏；托盘菜单退出才真退出。提醒依赖进程活着。
- 单实例：同一数据目录同一时刻只允许一个进程；第二次双击把已有窗口带到前台。
  两份进程会重复推送提醒、版本戳撞车，所以这是硬限制。

## 13. 给开发者

```powershell
.venv\Scripts\python.exe -m pytest -q                 # 全量回归测试
.venv\Scripts\python.exe -m qingdan call task.list    # 任意功能的 CLI 入口
.venv\Scripts\python.exe -u scripts\dev_fake_cloud.py # 假 Gitee + 本地裸仓库，不联网验同步
```

`dev_fake_cloud` 起来后用任意非空令牌登录，「立即同步」会真往本地裸仓库推；删一条再同步，
仓库里那条变 `deleted: true` 而非文件消失。`QINGDAN_DEMO_SKEW_MS=600000` 可演示钟差挡推送。

**架构与规矩**：

1. 做一个功能就必须有它的接口（`@feature` 一处声明，三入口派生）。
2. 后端只回机器键（`label_key` / `reason_key` / `direction`），界面文案归前端 i18n；
   契约测试用全 ASCII 用户数据跑遍所有接口，响应体出现汉字即失败。
3. 时间统一走 `core/stamp.py` 时间缝；日历侧与毫秒侧各有 AST 静态守卫，豁免表登记理由。
4. 前端语法用 `node --check` 按 ES 模块守卫；窗口全局 error 钩子把渲染异常顶到屏幕上
   （模板漏 `}` / TDZ 这类"测试全绿但白屏"的故障不许静默）。
5. 体积门禁 42MB（`scripts/check_size.py`，实测约 40.5MB）；图标按尺寸原生绘制保证 16px 可辨认。
6. 同步永不 `git pull`：fetch + 应用层三方合并；凭据不落明文（见 §8）。

**目录结构**：

```

├── src/qingdan/
│   ├── core/          # 模型/存储/时钟/注册表/视图/合并/同步/rrule/告警/备份/导出/访问控制
│   ├── api/           # registry → Starlette Route（按具体度排序挂载）
│   ├── adapters/      # 系统通知渠道（气泡→对话框→toast 降级链）

├── packaging/         # qingdan.spec / entry.py / cli_launcher.cs / 图标
```

## 14. 已知限制（不说清楚等于没写）

- **没有代码签名**：首次运行手动放行（§2）。
- **邮件渠道未真跑端到端**：实现与测试齐备，缺一份真实 SMTP 授权码做确认（钉钉已实测收信）。
- **通知正文是中文**：服务端生成，不随界面语言切换；界面文案双语。
- **服务端兜底提醒未做**：关机期间不提醒。远期方案（CI/云函数）在设计文档 §12.5 留了位置与纪律。
- **番茄专注未做**（界面上没有入口，不留"尚未实现"的空壳按钮）。
- WebView2 Runtime 缺失的机器打不开窗口（Win11 自带；Win10 装微软 Evergreen Bootstrapper）。
- 单实例硬限制（§12）。
- 重复规则的农历 / 法定工作日未做（需节假日数据，二期）。
