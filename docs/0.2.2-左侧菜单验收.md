# 0.2.2 左侧菜单优化

- 左侧移除「全部」，收集箱展示原全部视图中的任务及数量，包含已归属清单的任务；旧保存的 all 视图映射到收集箱。保留原数据和兼容 API。
- 清单、标签、过滤器均为五行视口、SQL 每页五条、相邻页预取，缓存不超过三页。支持滚轮、触控板及键盘滚动，滚动条隐藏。
- 新增或编辑三类条目时可选图标，默认保留 ▤、#、⚑。图标可恢复默认，持久化且支持同步、导入导出和 API/CLI。编辑过滤器保留原筛选规则。
- 增加 `filter.get`，过滤器编辑无须全量加载。

## 验证

- 前端、分页、组织结构及 HTTP/CLI 契约：102 项通过。
- 图标、隐式标签、SQL 分页及合并展示专项：30 项通过（与上组部分重复）。
- 浏览器验证收集箱同时显示已归属清单与未归属清单的任务，且没有 all 导航。
- 三类目录均为 180px 高，超过五条时内容可滚动；CSS/WebKit 滚动条均隐藏。
- 页面新增过滤器选择 ⭐、清单和标签选择 💼 后，API 返回相同图标，保存后弹窗关闭。
- 滚动过滤器到 220px，滚动位置保持，预取请求为 `/api/v1/filters?limit=5&offset=10`，DOM 不超过相邻三页。
- 冻结包验证通过：112 个接口、CLI、本机运行时转交、月度重复、前端资源一致性、远程权限、真实 HTTPS。体积 41.03 MB，低于 42 MB。
- 发布目录 `dist/release-0.2.2/Qingdan`；`清单-最新版.lnk` 已更新，沿用原数据目录。全部测试使用隔离数据。
