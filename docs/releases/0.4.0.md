## 规则与性能

- 中国大陆 2026/2027 离线工作日日历，支持重复任务跳过非工作日或顺延到工作日；未知年份明确提示。
- 保留原始周期锚点、COUNT/UNTIL、月末与闰年规则；长历史推进和预览不再受 5000 次遍历预算影响。
- 工作日锚点与提醒采用一致的本地时间基准，避免跨时区同步改变重复次数；全天任务推进后保留独立提醒时刻，普通重复提醒保留明确的时区偏移。
- 主列表与搜索每页 50 条，看板每组 5 列/每列 20 张；日历每格预览 3 条，更多事件按日分页。
- 相邻页提前加载、当前页替换及修订号校验，避免无限增加界面元素或使用过期缓存。

## 通知操作

- Windows 点击托盘通知打开提醒记录，再选择对应任务或完成/稍后。
- Android 单条任务通知支持打开、完成和稍后 10 分钟；批量提醒合并为分页入口。
- 旧通知和重复点击不会误推进下一次；任务已变化、已删除或已完成时显示相应结果。
- 托盘通知明确拒绝发送时报告失败，避免误记为已成功提醒。
- 通知版本校验与修改使用同一 SQLite 写事务，防止本地 CLI 在操作间隙改动任务。
- 本地提醒记录不进入同步，相关回调/记录接口不向远程 API 开放；现有 API/CLI 权限保持不变。

## 下载与升级

在本仓库 Releases 页面展开 Assets：Windows 选择 windows-x64 ZIP，解压后保留完整 Qingdan 文件夹并运行 Qingdan.exe；Android 选择 android-arm64 APK。Source code 是源码。

保留旧程序和数据；如数据不在默认位置，请使用 `Qingdan.exe app <原数据目录>` 指向已有数据。
Android 使用原固定签名；覆盖安装保留本地数据，卸载会清除数据。升级前可先备份或同步。

**所有同步设备升级后，再启用新的工作日规则。** 旧版本不理解这些扩展规则。
应用数据与同步 Item 格式保持兼容，新增通知记录属于设备本地数据。

Android 17 模拟器已覆盖原生通知、严格断网稍后、万条提醒/列表/看板和界面截图。
暂未取得安卓真机，厂商省电、实际锁屏/重启及真机覆盖升级仍待设备验收；后台执行受系统调度影响。
